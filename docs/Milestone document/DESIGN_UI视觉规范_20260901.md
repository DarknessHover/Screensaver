## 1. 设计原则

| # | 原则 | 落地方式 |
|---|------|---------|
| P1 | **一屏只有一个焦点** | 全屏唯一的品牌色块 = 状态 Hero 卡；顶栏退回中性 `surface` |
| P2 | **表面分层靠明度，不靠阴影** | 背景 `#F4F6FC` 比卡片 `#FBFCFF` 深一档，卡片"浮起来"；列表用色调 Card 而非 ElevatedCard |
| P3 | **形状即信息** | 同一段时间在 Hero 与规则卡上用同一个 `DayTimelineBar`，比例一致，靠形状辨认规则 |
| P4 | **静默不打扰** | 无规则时不渲染成"出错"：Hero 退回中性描边卡 + 空态文字指引，不用灰块/红字 |

## 2. 颜色（Theme.kt · 浅/深两套）

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| primary / onPrimary | `#3A5BDB` / `#FFFFFF` | `#9FB2FF` / `#0A1740` | 品牌色：FAB、选中态 Chip、时间条生效段 |
| tertiary / onTertiary | `#00796B` / `#FFFFFF` | `#6FD9C9` / `#00382F` | 「生效中」状态药丸 |
| error / errorContainer | `#B3261E` / `#F9DEDC` | `#FFB4AB` / `#93000A` | 警告 Banner、删除操作、时间轴"现在"竖线 |
| background | `#F4F6FC` | `#10111C` | 页面底色 |
| surface | `#FFFFFF` | `#16182A` | 顶栏 |
| surfaceContainerLow | `#FBFCFF` | `#1B1D30` | 卡片、未生效 Hero |
| surfaceContainerHighest | `#E5EAF5` | `#363A55` | 时间条底轨、未生效药丸底 |
| outline / outlineVariant | `#75777F` / `#C5C6D6` | `#8F919F` / `#3A3E58` | 描边（未生效 Hero、占位卡） |

- **表面层级阶梯**（浅色，由浅到深）：`surfaceContainerLowest #FFFFFF` → `Low #FBFCFF` → `Container #F1F4FB` → `High #EBEFF8` → `Highest #E5EAF5`。按"抬升多少"取档，不要各自随机取灰。
- **动态色关闭**（`Theme.kt:116 dynamicColor = false`）：本应用的功能就是换壁纸，而 Android 12+ 动态色取色源正是壁纸 → 主色会被用户刚换的壁纸牵着走（实测整屏变绿）。**品牌色与动态色二选一，选品牌色**；回退 = 改这一个布尔值。

## 3. 间距 / 圆角 / 尺寸（Dimens.kt）

- **Space**（4dp 基准网格）：`XS 4 / S 8 / M 12 / L 16 / XL 20 / XXL 24`；`Space.Screen = 20`（屏幕左右安全边距）。
- **Radius**：`S 8 / M 12 / L 16 / XL 20 / XXL 28`。卡片用 `XL(20)`，内部小图用 `M(12)`，对话框用 `XXL(28)`。
- **Sizes**：`IconBadge 32`（圆形徽标）、`IconS 18`（徽标内图标）、`TimelineThin 6` / `TimelineThick 10`。

## 4. 字阶（Type.kt · 三级，系统字体，不引自定义字体）

| 档位 | 样式 | 字号/行高 | 字重 | 字距 | 典型用途 |
|---|---|---|---|---|---|
| 一级 | `headlineMedium` | 28/34 | SemiBold | -0.2 | Hero 的起止时间 |
| 一级 | `titleLarge` | 22/28 | SemiBold | 0 | 顶栏标题 / 编辑器标题 |
| 二级 | `titleMedium` | 16/24 | SemiBold | 0.1 | 分区标题、规则时间 |
| 二级 | `titleSmall` | 14/20 | SemiBold | 0.1 | 卡片内小标题（如 Hero 域名） |
| 三级 | `bodyMedium` | 14/20 | Normal | 0.2 | 正文说明 |
| 三级 | `bodySmall` | 12/18 | Normal | 0.2 | 辅助说明、提示文案 |

| 标签 | `labelMedium` / `labelSmall` | 12/16 / 11/16 | Medium | 0.4 | 时长、状态药丸 |

## 5. 品牌渐变（Gradient.kt）

- 浅色 `#3A5BDB → #6B4BD1`；深色 `#3D55B8 → #5B3FBF`；左上→右下线性渐变。
- 两端**明度接近、色相不同**（ΔL < 0.015）：读作"颜色在流动"而非"一头亮一头暗"，副作用是**白字压在任何位置对比度都一致（实测 5.7–7.2:1，过 AA）**。
- **使用边界（硬）**：
  - ✅ 只给大面积品牌色块：**Hero 生效态、空态圆底图标**（64dp）。
  - ❌ FAB / Button / FilterChip / 小控件**一律纯色**——56dp 高的控件读不出渐变，只会显脏。
  - ❌ **禁止给 Material 组件设 `containerColor = Color.Transparent` 再自绘渐变**：`Surface` 会按 `tonalElevation` 叠一层覆盖，透明底会糊出脏色块（FAB 已踩坑并回退）。
  - 明暗判断取自 `colorScheme.surface.luminance()`，不二次读 `isSystemInDarkTheme`（保证与主题实际采用的方案一致）。

## 6. 组件规范

### 6.1 顶栏 `TopAppBar`
- 容器 `surface`，标题 `onSurface` + `titleLarge`；**不用 primaryContainer**（否则与 Hero 抢焦点）。
- 首页：纯标题「定时屏保」，无操作项。编辑器：标题「新建规则 / 编辑规则」+ 返回箭头（`Icons.Filled.ArrowBack`）。

### 6.2 域切换器 `SingleChoiceSegmentedButtonRow`（首页顶部）
- 两选项 `WallpaperDomain.entries`，文案取 `WallpaperDomain.labelOf()`（屏保壁纸 / 桌面壁纸），图标 `Lock` / `Home`。
- 选中态由 `SegmentedButton` 自身控制，**不额外上品牌色**（避免与 Hero 争焦点）。

### 6.3 状态 Hero 卡（全屏唯一品牌色块）
- 圆角 `Radius.XL(20)`，内边距 `Space.L(16)`。
- **生效态**：品牌渐变铺满 + 白字；右上「生效中」= **白色描边药丸**（`border 1dp White 75%` + 白字），不用实心色（渐变上实心色随时与底相撞）；下方 `DayTimelineBar` 用 `TimelineThick(10)` + 白色 25% 底轨 + 白色段 + 白色"现在"竖线。

  > 例外：Hero 内的"现在"竖线在渐变上用**白色**，与列表项的 `error` 红线不同，属刻意设计。
- **未生效态**：`surfaceContainerLow` 纯色 + `outlineVariant` 1dp 描边 + 中性图标 + 「未生效」药丸（底 `surfaceContainerHighest`）；文案「当前无该域生效规则，保持已有XX」。

### 6.4 规则卡 `Card`
- `surfaceContainerLow` + `Radius.XL(20)`；**生效中的那条**加 `primary 45%` 1dp 描边 + `tertiary` 药丸「生效中」。
- 主信息 = 起止时间（`titleMedium`），副信息 = 时长（`bodySmall`），下方 `DayTimelineBar`（细 6dp，段色 `primary`；非生效段 `primary 55%`）。
- 右侧两个图标按钮：编辑（`onSurfaceVariant`）、删除（`error` 色）。删除走 `AlertDialog` 二次确认（圆角 `XXL 28`，主按钮文字用 `error` 色）。

### 6.5 时间条 `DayTimelineBar`（共用组件）
- 默认细条 6dp（`TimelineThin`），Hero 传 `TimelineThick(10)`；底轨 `surfaceContainerHighest`，生效段 `primary`。
- 传 `nowMinute` 才画"现在"竖线（2dp，`error` 色）——**规则列表项不传**，避免满屏红线。
- 位置按 `minute / 1440f` 比例计算，Hero 与列表同一段区间比例完全一致。

### 6.6 精确闹钟警告 Banner
- `errorContainer` 底 + `onErrorContainer` 文字 + `error` 圆形徽标（32dp）内白色警告图标；右侧「去授权」`TextButton`（跳系统设置，失败回退应用详情页）。
- 仅在 API 31+ 且未授权时显示。

### 6.7 空态 `EmptyRulesHint`（2026-09-01 修订）
- 构成：品牌渐变圆底（64dp）+ 白色 `DateRange` 图标（28dp）→ 标题「还没有XX规则」（`titleMedium`）→ 说明「点击右下角「新建」，选一张图并设定生效时段」（`bodySmall`，`onSurfaceVariant`，居中）。
- **不内嵌任何按钮**：主操作由 Scaffold 级常驻 FAB 承担。二者曾构成"同屏两个新建入口"，已去重。
- 空态只负责"告诉用户下一步是什么"，不负责提供第二个点击目标。

### 6.8 FAB
- 首页：`ExtendedFloatingActionButton`，`primary` 纯色 + `onPrimary` 内容，图标 `Add` + 文字「新建」（`labelLarge`）。**常驻显示**（有规则/无规则都在），是新建的唯一入口。
- 编辑器：`FloatingActionButton`，**未选图或保存中 → 容器 `surfaceVariant`、内容 `onSurfaceVariant`**（视觉禁用），保存中显示 24dp 进度圈而非对勾；可保存时 `primary` + `Check` 图标。

### 6.9 编辑器分段卡 `SectionCard`
- 三段：壁纸域 / 时间段 / 壁纸图，段间 `Space.L(16)`。
- 壁纸域：两个 `FilterChip` 等宽（`weight 1f`），选中 `primary` 容器 + `onPrimary` 文字；下方 `hintOf()` 说明文字。
- 时间段：起止两张可点 `TimeCard`（弹 `TimePicker` 精调）+ 说明「灰带为其他规则已占用时段，请避开」+ 时长（`labelMedium`，`primary` 色）+ `TimeAxisPicker`。
- 壁纸图：未选 = 描边占位卡（`surfaceContainerLow` + `outlineVariant`），内含 56dp 圆形 `primaryContainer` 底 + `Add` 图标 + 引导文案；已选 = 200dp 高 `Crop` 预览 + 「更换 / 移除」（移除文字用 `error` 色）。
- 反馈统一走 `Snackbar`（冲突、未选图、保存成功/失败），由 `RuleEditorViewModel.events` 抛出。

## 7. 交互与反馈规则

1. **保存前置校验**：未选图 → 禁用态 FAB（视觉先行）+ 点击无副作用；仍触发则 Snackbar「请先为规则选择一张素材图片」。
2. **冲突反馈**：时间区间与同域已有规则重叠 → Snackbar 指明冲突区间「与 HH:MM–HH:MM 的时间段冲突」，且不落库。
3. **幂等**：保存中 `saving = true`，拒绝重复提交（防止连点产生多条相同规则）。
4. **实时性**：首页前台每 60s 重算"当前生效规则"，`ON_RESUME` 亦重算（暖启动不走 `onCreate`）；Hero 的"现在"竖线同步每分钟刷新。
5. **域继承**：新建规则的壁纸域 = 进入编辑器前首页停留的域（路由 `editor/-1?domain=`），编辑时以规则自身域为准。

## 8. 图标与文案

- 图标一律取 `Icons.Filled.*`，实际使用：`Add`（新建/选图）、`Edit`、`Delete`、`Lock`（屏保）、`Home`（桌面）、`CheckCircle`（Hero 生效）、`Info`（Hero 未生效）、`Warning`（警告 Banner）、`DateRange`（空态/时间段）、`Settings`（壁纸域）、`Favorite`（壁纸图）、`ArrowBack`（返回）、`Check`（保存）。
- 域名文案集中在 `WallpaperDomain.labelOf()` / `hintOf()`，**界面不得另写一份**（避免同一概念两种叫法）。
- 状态词固定两态：「生效中 / 未生效」。

## 9. 无障碍与对比度（实测基线）

- 品牌渐变上白字 **5.7–7.2:1**（过 AA）；`surfaceContainerHighest` 上正文 **8.4:1**；深色 `primary` 对 `surface` **8.6:1**。
- 渐变上的次级文字用 `White 90%` 而非 75%（渐变底比浅色容器深，压太狠会掉出 AA）。
- ⚠️ **"配色随图变"必须加护栏**：`image/splash` 18 张素材的 Palette vibrant 取色有 **7/18（39%）** 在白底上对比度 < 4.5。若将来启用取色，必须先做对比度校正，否则直接违反 AA。Material3 1.2.1 无公开 `seed → ColorScheme` API，需自行实现。
