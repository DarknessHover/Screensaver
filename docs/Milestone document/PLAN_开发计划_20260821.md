## 已交付（MVP）

- **工程脚手架**：Gradle(Kotlin DSL) 8.9 + **JDK 21** + AGP 8.5.2 + Kotlin 1.9.24（Compose Compiler 1.5.14）；依赖 Compose BOM 2024.06.00 / Room 2.6.1 + KSP / Coil / Navigation / Lifecycle；包结构 `ui / domain / data / scheduler / di`；min24 / target34 / compile34。
- **规则编辑**：`TimeAxisPicker`（0–24h 直线拖选，含「现在」竖线、占用区间灰带）+ `TimePicker` 弹窗精调；`RuleEditorViewModel` 做**禁重叠校验**（`occupiedIntervals` + `overlaps`），规则内 SAF 选图（未选图/重叠则禁止保存）；**新建规则默认域继承首页当前 Tab**（2026-09-01）。
- **调度引擎**：`ScheduleEngine`（纯函数，按域解析）+ `AlarmScheduler`（`setExactAndAllowWhileIdle`，未授权降级 `setAndAllowWhileIdle`，取消后重排 + 自愈）+ `BootCompletedReceiver`（开机/更新后重排 + 立即应用）+ `WallpaperSwitchReceiver`（到点切换）。
- **渲染**：`WallpaperApplier` 按域单设——`LOCK → FLAG_LOCK`、`SYSTEM → FLAG_SYSTEM`（API < 24 无 FLAG 区分，锁屏直接返回 false）；降采样解码防 OOM；锁屏失败进程级缓存。
- **亮屏补偿（v9）**：`ScreenOnReceiver` 动态注册，收到 `ACTION_SCREEN_ON` 后仅对 LOCK 域重设当前壁纸。
- **立即应用**：`MainActivity` 启动 / 保存规则 / 开机 / 闹钟到点 均汇入唯一入口 `AppContainer.applyCurrentNow()`；首页「立即应用」可手动预览。
- **精确闹钟引导**：API 31+ 未授权时首页 Banner 一键跳转系统设置。
- **单元测试（v9 已交付）**：`ScheduleEngineTest` **15 个用例**（JVM 秒级），回归命令 `:app:testDebugUnitTest`。
- **启动页零自绘（2026-08-30）**：删除 `SplashActivity` 与 `assets/splash`，`MainActivity` 直接为 launcher，只保留系统 SplashScreen 一帧；APK 12.4MB → 10.16MB。

## 当前范围边界（对齐代码）

- 每规则 1 张图（无图片库）；无 `priority`；无启用开关（所有规则默认生效）；无跨午夜自动拆分（需用户手动建两条）；每天循环固定。
- 素材仅本地（SAF），绝不上传网络（NF1）。

## 风险

- **R2** 国产 ROM 锁屏壁纸限制 → 按域降级（锁屏失败缓存）+ 日志提示；必要时引导手动设锁屏。
- **R3** 精确闹钟被厂商限制 → 电池优化白名单引导（待迭代）。
- **R6** 模拟器闹钟不可靠 → **真机实测为必经环节**，勿仅靠模拟器验收；且国产 ROM 限制在原生模拟器上测不出。
- **R5** 缺测试（**已部分缓解**）→ `ScheduleEngine` 已有 15 个单测；`WallpaperApplier` / `AlarmScheduler` / 各 Receiver 仍只能真机或 adb 验证，集成层零自动化。
- **R7（新增）** 国产 ROM 后台/省电策略 → 直接导致定时切换失效，是当前最高优先级问题；缓解依赖白名单引导，无法从根本上免疫 force-stop。
